# Four-method statistical implementation constraints

Preserve Stage1 EDA before preprocessing authorization; Stage2 assesses four methods without fitting; Stage3 has execution permission and a separate result-confirmation gate; Stage4 performs only budget-bound diagnostics and proposes one final model or none; Stage5 requires final delivery confirmation.

K-means uses sklearn Lloyd with explicit init,n_init,seed,tol,max_iter; not Hartigan–Wong. Hierarchical preserves actual SciPy linkage and cut_tree, Ward Euclidean only. DBSCAN uses approved geometry, no prescribed K, counts core/border/noise and allows all-noise/single-group. PAM remains deterministic BUILD/SWAP with fixed ties and only local 1-swap optimality.

Gower retains declared ordinal levels, symmetric/asymmetric binary semantics, positive weights, pairwise missing denominators, constant omission and rejection of undefined pairs. No Euclidean CH/DB for Gower. Silhouette undefined groups remain NA. ARI compares identical unique IDs; common-ID subsampling max-Jaccard is not Hennig bootstrap. Missing original groups and failed resamples remain visible. Fixed full-data preprocessing is distinct from refit policy and does not include scaling-estimation uncertainty.

Scientific solvers are preserved from rc4; use new evidence summaries only as descriptive support. No universal stability pass threshold, composite score, natural-group proof, causal naming or naive post-selection p-values. See RC5_SELECTION_EVIDENCE.md for outputs and interpretation.
